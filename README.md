# Holistic Disability Development Organization (HDDO)

Official website and digital assets for **Holistic Disability Development Organization (HDDO)**, an Ethiopian non-governmental organization founded to promote the rights, dignity, and full inclusion of persons with disabilities across Ethiopia, starting in the Somali Regional State.

## 🌐 Live Website
- **URL:** [https://holisticdisability.org](https://holisticdisability.org)
- **Contact:** info@holisticdisability.org
- **Location:** Jigjiga, Somali Regional State, Ethiopia

## 📁 Project Structure
- `dist/`: Production website files (`index.html`, stylesheet, and visual assets).
- `dist/assets/`: Brand imagery, partner logos, and leadership media.
- `.openai/`: Deployment configuration for static hosting.

## 🚀 Running Locally
Open `dist/index.html` in any modern web browser or serve via a local HTTP server:
```bash
python -m http.server 8000 --directory dist
```
